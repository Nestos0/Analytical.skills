# Analytical.skills

A collection of reusable analysis skills for AI agents.

## Included

- SKILL.md — Universal Discourse, Authority, Identity, Technology, and Legitimacy Analysis

## Purpose

This skill helps agents analyze texts beyond truth-value evaluation by examining:

- hidden assumptions
- legitimacy construction
- authority claims
- identity performance
- social incentives
- technological mediation

## Usage

Provide a text and apply the six-step workflow:

1. Plain-Language Compression
2. Hidden Premise Extraction
3. Functional Classification
4. Persona Classification
5. Environmental Mapping
6. Structural Conclusion

## Expected Output

- Plain-Language Rewrite
- Hidden Premises
- Pragmatic Function
- Persona Strategy
- Environmental Mechanism
- Structural Conclusion

## Compatible Agents

Claude Code, OpenCode, Codex, Antigravity, Pi, Roo Code, Cline, Aider, Gemini CLI and similar agent frameworks.
