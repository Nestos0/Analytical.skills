# Test Cases

## Test 1

Text:
"AI will replace all programmers within five years."

Expected Checks:
- prediction vs certainty
- authority source
- hidden premises
- technological determinism

## Test 2

Text:
"Scientific management proves this is the only rational solution."

Expected Checks:
- useful -> mandatory substitution
- legitimacy construction
- authority-occupying persona

## Test 3

Text:
"Dialectics shows history inevitably moves toward this outcome."

Expected Checks:
- framework competition
- inevitability claim
- interpretation authority

## Validation

A successful analysis should identify:

1. Plain-language meaning
2. Hidden premises
3. Pragmatic function
4. Persona strategy
5. Environmental mechanism
6. Structural conclusion
